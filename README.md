# Md Shohel Rana — GitHub Pages portfolio

This editable static website is prepared for the public repository **srana06006/shohel.rana**.

## Publish at GitHub Pages

1. Upload the contents of this folder to the repository root, including the assets folder, favicon.ico, index.html, and Md-Shohel-Rana-CV.pdf.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. After GitHub finishes deploying, open https://srana06006.github.io/shohel.rana/

The repository and Pages site are public, so the profile photo and CV in this folder will also be public.

## Edit the site

- Edit **index.html** for structure and styles.
- Edit **assets/i18n.js** to update the English and Bangla text. The selector changes the page without a reload and remembers the visitor's choice in that browser.
- Replace **assets/shohel-rana-profile.jpeg** to change the profile photo in both the hero and the header.
- Replace files in **assets/logos/** to change institution and employer marks.
- Replace **Md-Shohel-Rana-CV.pdf** to update the downloadable CV.

All site asset paths are relative and work from the shohel.rana project Pages URL.
